# Restore CLINICAL 疗程规划器 — 开发规格

给 Claude Code 用的需求说明。参考原型：`clinical-planner.html`（单页 HTML，逻辑都在 `<script>` 里，可以直接照搬公式和数据）。

## 1. 这个系统要做什么

营养师为买了 CLINICAL 配套的顾客排疗程方案：

- 每个配套有固定售价，还有一组**必含项目**（海报上承诺的内容，数量不能减少）。
- 扣掉必含项目后，剩下的疗程预算由营养师按顾客情况自由加配。
- 系统即时显示：预算用了多少、顾客看到的方案总价值有没有达标。
- 营养师**看不到成本和利润**，管理层可以看到全部。

## 2. 核心公式（每个配套）

```
净额        = 售价 ÷ (1 + SST)            # SST = 8%，售价是含税价
手续费      = 售价 × 手续费%               # 默认 5%，可设定（3%–8% 不等）
可分配      = 净额 − 代理佣金（固定 RM） − 手续费
保底        = 可分配 × 保底%               # 公司利润，不动
疗程预算    = 可分配 − 保底                # 以「成本」计算
方案成本    = Σ 数量 × 项目成本
方案总价值  = Σ 数量 × 项目售价             # 呈现给顾客看的价值
价值目标    = 售价 × 价值倍数
利润        = 可分配 − 方案成本            # 方案成本 ≤ 疗程预算时，利润 ≥ 保底
```

验收规则：

- 方案成本 > 疗程预算 → 显示「超出预算」，**不能提交**（或需要管理层批准）。
- 方案总价值 < 价值目标 → 显示警告，可以提交，但提醒营养师加配高价值、低成本项目。
- 任何项目的数量不能低于该配套的必含数量。

## 4. 深度验血：营养师自己勾选 marker

验血不用固定配套。每个顾客的验血由营养师按情况勾选 marker 组合：

- **每次验血的售价 = 勾选组合的售价加总；成本 = 勾选组合的成本加总。**
- 「标准健康检查」一定要验，不能取消。
- **建议上限：每次售价约 RM1,250**（管理层可调）。超过时显示警告，需要减少 marker 或经管理层同意。
- 同一个方案的前后验血用同一组 marker，才能对比。
- **成本以较高地区的成本为准**（KL 与外州成本不同时，取较高的那个）。
- marker 的价目和成本请接现有的 Cost Calculator JSON（验血价格的单一来源），不要另外维护一份。

## 6. 成本假设（管理层可调）

- 营养师每分钟成本 = 日薪 RM250 ÷ (4.5 个 60 分钟 consult × 60) ≈ RM0.926
- 智能健康追踪每月成本 = 平台每人 RM40 + 平台固定费 RM650 ÷ 同时在用人数（默认 30）+ 每周 10 分钟看数据 × 4.33 周 × 营养师每分钟成本
- 付款手续费默认 5%
- 所有对外和顾客看到的地方，一律称为「智能健康追踪 / 智能健康戒指」，不显示追踪平台供应商的品牌名。

## 7. 权限与可见范围

| 内容 | 营养师 | 管理层 |
| --- | --- | --- |
| 项目和 marker 售价、方案总价值、价值目标 | ✓ | ✓ |
| 勾选验血 marker | ✓ | ✓ |
| 预算已用 %、必含项目占预算 % | ✓ | ✓ |
| 项目成本、疗程预算金额、净额、佣金、手续费、保底、利润 | ✗ | ✓ |
| 修改价目、配套设定、成本假设 | ✗ | ✓ |

注意：原型是前端隐藏成本，懂技术的人看源代码还是看得到。正式系统里，**成本和利润只能由后端按权限返回**，营养师的接口完全不回传成本。

## 8. 正式系统要加上的功能（原型没有）

1. **登入和角色**：营养师、管理层（Levin / Jayden / Amanda）。
2. **储存方案**：顾客、配套、各项目数量、营养师、日期、状态（草稿 / 已提交 / 已批准）。
3. **超预算审批**：超出预算的方案要管理层批准才能生效。
4. **执行追踪**：每完成一次疗程就记录一次，显示每项已用 / 剩余次数。
5. **顾客方案输出**：分「配套包含」和「按你的情况加配」两部分，列出每项价值、方案总价值和配套价格，可以复制到 WhatsApp 或导出 PDF。
6. **价目版本**：价目或成本修改后，已成交的方案保留成交当时的价格和成本。

## 9. 已知情况

- CLINICAL 心血管光是必含项目就用掉约 95% 的预算，营养师加配空间很少。要加配，需要调高售价，或调低保底 %。
- 验血 marker 勾得越多，疗程预算就越少，营养师要在验血和其他疗程之间取舍。
- 「待确认」的价格和成本都是估算，上线前要换成实际数字。
